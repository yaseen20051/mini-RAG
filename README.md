## Installation 

### Install the required packages 

```bash 
$ pip install -r requirements.txt
```

### Setup the environment vaiables 

```bash
$ cp .env.example .env
```

Set your environment vaiables in the `.env` file. Like `OPENAI_API_KEY` value.
